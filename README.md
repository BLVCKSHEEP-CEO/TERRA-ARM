
### **Project Description**

**TERRA-ARM (Terrain Adaptive Robotic Assistant for Real-world Mobility)** is a multi-purpose 4WD all-terrain robot equipped with a robotic arm, firefighting system, environmental monitoring sensors, and autonomous navigation. Built on a Raspberry Pi and Arduino platform, it can operate on land and water, using advanced electromechanical systems including brushless motors for aquatic movement. It is designed for environmental exploration, hazard response, and remote assistance.

---

### **Why I Made This Project**

I was inspired by Thermite firefighting robots and bomb disposal robots used by SWAT teams. Recently in Ghana, there have been frequent fire outbreaks, especially in market areas, and I wanted to create a safer way to respond to such emergencies without risking human lives. Having previously built several 4WD Arduino cars, I challenged myself to integrate my skills into a more advanced and purposeful robotic system.

---

### **How to Use the Project**

TERRA-ARM has two control modes: Web Mode (via WiFi using a mobile phone) and Gamepad Mode. In both modes, users can view live video from the onboard webcam. The controls are similar to a remote-control car, clearly labeled and beginner-friendly. The robot can be driven on-road, off-road, and even on water, while also operating its robotic arm and monitoring environmental conditions.
